# Unicode similarity scoring acceptance — 2026-10-04

This follow-up repairs the tokenizer on the existing [PR #259](https://github.com/Prompt-Hash-Stellar/prompt-hash/pull/259), which addresses [issue #242](https://github.com/Prompt-Hash-Stellar/prompt-hash/issues/242). The previous long-text tokenization discarded non-ASCII letters. Identical Russian, Arabic, and Japanese drafts could receive a zero similarity score; unrelated multilingual drafts could be falsely blocked because only their shared English title remained.

The one-line service change retains Unicode letters, combining marks, and numbers. Two cases were added to the existing detection test file, covering multiple scripts, supplementary-plane letters, shared-title false positives, and distinct Hindi vowel marks. Existing whitespace tokenization, short-text routing, thresholds, and override behavior are retained. Language-specific segmentation and canonical Unicode normalization are outside this repair.
